## 🎯 First Steps

### Step 1: Create Members (Admin)
- Go to Admin Dashboard
- View "All Members Status" table (will be empty initially)
- Register new members (logout and use register form)

### Step 2: Generate Monthly Contributions (Admin)
- On Admin Dashboard, select current month
- Click "Load Report"
- Contributions auto-generate for all members

### Step 3: Assign Collectors (Admin)
- Select 2 members from dropdowns
- Click "Assign" or "Auto-Rotate"
- Collectors are now assigned

### Step 4: Members Record Payments
- Members login to their dashboard
- See current month status
- Record payment in "Record Payment" section
